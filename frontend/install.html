HOW TO INSTALL

怎麼安裝到主畫面？

安裝之後才能收到推播通知。整個過程只要幾秒鐘，跟著下面的步驟做就可以了。

📱 iPhone（Safari）

  1. 用 Safari 打開這個網站（不能用 LINE、Messenger、Instagram 裡面打開的瀏覽器，也不能用 Chrome，一定要是 Safari）
  2. 點畫面下方（或上方）工具列中間的「分享」按鈕（一個往上的箭頭，從方框裡跳出來的圖示）
  3. 往下滑動選單，找到「加入主畫面」並點下去
  4. 右上角會出現「新增」，點一下
  5. 完成！主畫面上會出現「國小午餐通知」的圖示，之後請都從這個圖示打開，才能設定通知

⚠️ 如果是從 LINE、Instagram 等 App 裡面點連結打開的，畫面右下角或右上角通常會有「用瀏覽器打開」或類似的選項，選下去改用 Safari 打開，再照上面的步驟做。

🤖 Android（Chrome）

  1. 用 Chrome 打開這個網站
  2. 點畫面右上角的「⋮」（三個直排小點）選單
  3. 選單裡找「安裝應用程式」或「新增至主畫面」（不同手機顯示的字可能不太一樣）
  4. 點「安裝」
  5. 完成！主畫面上會出現圖示，之後請都從這個圖示打開，才能設定通知

⚠️ 如果手機沒有自動跳出安裝選項，也可以直接在網站上點「加入主畫面」按鈕（在選擇學校那張卡片裡）。

安裝好之後，回到服務首頁選擇學校並開啟通知。
