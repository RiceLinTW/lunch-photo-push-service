## Why

家長不知道自己學校的 SchoolId，目前只能手動連到「校園食材登錄平臺」官方查詢頁自己查代碼再回來輸入。調查證實該平台的即時學校清單端點（`/school?CountyId=&AreaId=&SchoolType=`）需要一把未公開發放的存取金鑰，我們不會取得或重放；地方政府自行開放的資料集也查證過三個縣市（桃園、宜蘭、臺南）均無法提供可用的對照資料。改為完全自建：用教育部官方公開、全國完整、免授權的學校名錄資料，讓家長直接在我們自己的服務內用縣市+學校名稱搜尋，取代連到對方網站這一步。

## What Changes

- 新增學校名錄資料：匯入教育部統計處公開的國小/國中/高中名錄（SchoolCode、學校名稱、縣市）到自己的 D1
- 新增站內搜尋：使用者輸入縣市 + 學校名稱關鍵字，從自己的資料庫搜尋，不再連到對方查詢頁
- 新增代碼驗證邏輯：選定學校後，嘗試以教育部代碼查詢對方平台的即時菜單資料；查到真實資料才視為可用的 SchoolId 並繼續訂閱流程
- 新增已驗證代碼快取：一旦驗證成功，記住該校「教育部代碼 = SchoolId」的結果，之後同校不需要重新驗證
- 修改前端選校 UI：從原本「連結到官方查詢頁 + 手動輸入代碼」改成站內搜尋為主要路徑，手動輸入代碼保留作為備援（驗證失敗時的退路）

## Capabilities

### New Capabilities

- `school-directory-search`: 教育部學校名錄的匯入、站內縣市/名稱搜尋、選定學校後的 SchoolId 驗證與快取

### Modified Capabilities

(無：既有訂閱 API 本身不變，只是前端取得 schoolId 的方式改變)

## Impact

- 新增資料匯入來源：data.gov.tw 教育部統計處學校名錄（國小/國中/高中三個資料集），需定期（例如每學年）重新同步
- 對 fatraceschool 平台的查詢量增加：每次使用者「選定學校」時會多一次驗證查詢，但頻率與現有輪詢邏輯同數量級，不涉及批次查詢
- 前端選校流程改變，原本連到官方查詢頁的做法保留在「找不到/驗證失敗」時的備援說明文字中，不完全移除
